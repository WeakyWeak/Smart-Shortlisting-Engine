# Cyber Security Intern
**SentinelGrid**

## Responsibilities
- Perform vulnerability assessments on internal web applications.
- Run network scans and document findings.
- Assist with incident response and log analysis.
- Write remediation guidance for engineering teams.

## Required Skills
- Network security fundamentals and TCP/IP.
- Penetration testing methodology.
- Experience with Nmap and Wireshark.
- Familiarity with Burp Suite for web application testing.
- Linux command line proficiency.
- Understanding of the OWASP Top 10.
- Vulnerability assessment and reporting.

## Preferred Skills
- Exposure to Metasploit or Kali Linux.
- Scripting in Python or Bash.
- SIEM tooling such as Splunk.
- Cryptography fundamentals.
