# Mobile App Developer Intern
**Orbital Mobile**

## Responsibilities
- Build cross-platform mobile applications.
- Implement responsive UI screens and state management.
- Integrate backend services and REST APIs into the app.
- Publish and maintain builds on app stores.

## Required Skills
- Mobile development with Flutter or React Native.
- Proficiency in Dart, Kotlin or JavaScript.
- Experience integrating REST APIs.
- Firebase for authentication and data storage.
- Version control with Git.
- Understanding of mobile UI/UX principles.

## Preferred Skills
- Native Android SDK experience.
- Android Studio and Xcode familiarity.
- SQLite or local persistence.
- Play Console release experience.
