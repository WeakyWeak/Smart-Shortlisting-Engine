# Junior Full Stack Developer Intern
**TechNova Solutions**

## About the Role
TechNova Solutions is looking for a Junior Full Stack Developer Intern to join our
fast-moving product engineering team. You will work across the stack, shipping
features end to end alongside senior engineers. We want a rockstar developer who can
hit the ground running.

## Responsibilities
- Build and maintain responsive user interfaces using React.
- Develop and integrate REST APIs for our core web platform.
- Write backend services in Node.js and Express.
- Design and query relational database schemas in PostgreSQL.
- Collaborate with designers to translate mockups into working components.
- Participate in code reviews and use Git for version control.
- Write unit tests and help maintain our CI/CD pipeline.
- Debug production issues and contribute fixes.

## Required Skills
- Proficiency in JavaScript and modern ES6+ syntax.
- Hands-on experience with React for frontend development.
- Experience with Node.js backend development.
- Working knowledge of REST API design and integration.
- Familiarity with PostgreSQL or relational database concepts.
- Version control with Git and GitHub.
- Understanding of HTML and CSS fundamentals.
- Strong problem solving and communication skills.

## Preferred Skills
- Exposure to TypeScript.
- Experience with Docker or containerised development.
- Familiarity with MongoDB or NoSQL databases.
- Experience with cloud platforms such as AWS.
- Knowledge of testing frameworks such as Jest.
- Prior internship or personal full stack projects.

## Qualifications
- Currently pursuing a Bachelor's degree in Computer Science or a related field.
- Available for a full-time 6-month internship.
- Portfolio of personal projects or an active GitHub profile.
